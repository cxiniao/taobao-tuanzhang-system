## 解决什么问题

招商团长的日常，通常散在四个地方：联盟后台、商家微信群、Excel、财务表。

| 现在 | 代价 |
| --- | --- |
| 团长号来回切，活动重发一遍 | 账号越多，人越像复读机 |
| 报名在群里收，审核靠人盯 | 漏审、错审，商家流失 |
| 商品被挖、佣金被调低，事后才知道 | 量掉了才查，已经晚了 |
| 订单等平台月结，提成月底手算 | 账算不清，人留不住 |

这套系统把它们串成一条线：

**账号统一接 → 活动统一发 → 报名统一审 → 订单统一拉 → 结算统一算 → 业绩统一分。**

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 团长账号 | 淘宝团长号统一授权，在线 / 掉线状态可见 |
| 招商活动 | 淘宝 7 类活动（普通招商 / 官方营销 / 渠道招商 / 自营货品 / 超级U选 / 营销宝 / 超级淘客）；可指定商家、设置报名截止与活动要求 |
| 报名审核 | 商家自主报名，批量通过 / 拒绝；排期时间、服务费率、预估效果同屏 |
| 商品管理 | 在线、佣金变动、被挖、到期（昨 / 今 / 明 / 7 天）分表；四级风险提示：服务费无风险 / 有风险 / 团队内部撞单 / 需自行核实 |
| 订单中心 | 付款、结算、失效、维权四种状态；按活动 / 商品 / 店铺 / 团长号筛选；单次 5 万条导出 |
| 结算分账 | 预估服务费与结算服务费分列，结算自动扣维权退款；按员工、小组、站点三层出账 |
| 招商截图 | 活动、订单、联盟后台数据直接出图给商家，不用手动拼图 |
| 组织权限 | 角色—菜单—按钮三级权限；员工挂小组；首页排行榜可按角色开关 |
| 数据看板 | 成交概况、员工 / 店铺 / 商品榜、本月服务费趋势 |

## 几个实用的细节

- **被挖商品单独成表。** 别的团长把商品撬走，系统按“被挖时间”列出来，不用一个个翻。
- **佣金变动可追溯。** 商家偷偷降佣，商品会进“佣金变动”页，配合服务费风险提示，决定继续推还是撤。
- **结算口径分开。** 预估是预估，结算是结算，维权退款自动扣掉，财务不用二次核对。
- **批量审核。** 一次勾选，批量通过或拒绝；拒绝可填原因。

## 三种合作方式

| 方式 | 适合谁 | 交付 | 计费 |
| --- | --- | --- | --- |
| **SaaS 租用** | 想先跑起来、不想碰服务器的团队 | 独立实例、独立域名、账号开通、版本升级与运维 | 按年 |
| **贴牌部署** | 有客户资源、想做成自己产品的服务商 / MCN | 换 logo、名称、域名、主题色，独立部署，界面无原品牌痕迹 | 按年授权或买断 |
| **源码交付** | 要自己掌控、要二次开发的团队或公司 | 前端 + 后端 + 数据库 + 部署文档，一次性买断 | 一次性 |

三种方式都支持**先远程演示，看完系统再谈**。

源码交付包含：前端工程、后端服务、数据库结构、部署文档（环境、安装、Nginx、定时任务）、一次部署协助、30 天缺陷修复。不含平台账号与资质、服务器与域名、第三方服务费用。

节奏：SaaS 1 个工作日开通；贴牌 3–5 个工作日；源码当天打包，部署协助另约。

**其他平台：抖音、快手、京东、视频号的招商团长系统也可以开发，单独聊。**

## 合作流程

1. 说明团队规模、现在做的平台、想用哪种模式。
2. 约 15 分钟远程演示，看首页、审核、订单、结算。
3. 确认模式、账号数与功能范围，出报价。
4. SaaS 开通，或贴牌 / 源码部署。
5. 交付后 30 天内缺陷修复。

## 常见问题

**为什么仓库里没有代码？**
这是一套在运营的商业系统，源码是交付物，不公开。这里放介绍、功能与合作方式，方便先判断合不合适。

**能先看系统吗？**
可以，约时间远程演示，看首页、审核、订单、结算。合适再谈开通。

**贴牌能改到什么程度？**
logo、系统名称、浏览器标题、favicon、页脚、域名、主题色都能换，界面结构不变。

**源码交付后能自己改吗？**
能。交付的是完整前端、后端、数据库结构和部署文档，不加密。

**数据放在哪？**
SaaS 按独立实例部署，每个客户一套库，不混在一起。
